Kuraya Download

Buttons & controls

What every button, list and letter in Kuraya does. Hover any button in the app to see its name.

New here? Start with the Setup window, copy a few movies into your Inbox folder and press Process Inbox 📥. Then right-click a movie → Scrape Movie.

The top toolbar — left

Small icons next to the search box.

🔍Search boxType any part of a title, DVD-ID, actress, studio or genre. space = all words must match, , = any of them, + = genre AND genre. The ⓘ next to it explains the syntax; the clock icon shows your recent searches.
🖥️LogOpens the live log (also Ctrl+L). Useful when you report a problem.
🛡️Doctor GuardShows the background guard. Green = all fine; a number = issues it found. Click to see them and fix the safe ones.
▦Task ConsoleEvery job that runs in the background (subtitles, converter, metadata, guard). Tick a box to run that job, untick to stop it. Auto OFF means nothing starts by itself.
▶Resume scrapeOnly appears when you minimised a scrape — reopens it where it stopped.
⏷Taste filterBuild a "keep list" from your favourites. When active (red), movies outside your taste are marked as delete candidates.
📺TubeSearch the tube sites inside Kuraya, play in the built-in player and keep favourites.
🔎Identify unknown clipPick any video file — Kuraya finds out which film (DVD-ID) it is.
📂Local & LAN browserOpen any drive or network share and play movies straight away. Shows only movies; All movies lists every movie in all subfolders, Not in app hides the ones already in your library.

The big buttons — middle

The main jobs, always in the centre of the toolbar.

🆕New ReleasesThe newest films from the movie sites, with the ones you own marked. Press again to go back to your library.
🔄Scan LibraryReads all your library folders and the Inbox from disk again. Use it after you copied movies in with Explorer.
CCScan Burned SubsFinds movies whose English subtitles are burned into the picture.
📋Pre-InboxThe waiting room before the Inbox: joins multi-part movies (CD1/CD2), removes duplicates and lets you check everything before it moves on.
🕘Trash / HistoryUndo a recent delete, replace, rename or move while it is still in the trash.
📥Process InboxOrganises new files in your Inbox: finds the DVD-ID, checks for duplicates and moves each movie into the library.
👥Media ToolsActor photos and bios, metadata refill and the Movie Sorter (genre rules, synonyms, blacklists).
🩺DoctorA full health check of the library: missing covers, broken files, leftovers, wrong names. Shows what it found and fixes it on request.

The top toolbar — right

Small icons on the right.

⚙️SettingsAll options, grouped and searchable: folders, scrapers, subtitles, the player, the look.
🔍Check DuplicatesFinds the same film more than once (by DVD-ID, file content and sound) and lets you keep the best copy.
🧹Cleanup DuplicatesRemoves duplicate rows from Kuraya's list (not your files).
🗑️Clean CacheRepairs Kuraya's list quickly: wrong flags, double rows and entries whose folder is gone. Fast, no disk rescan, your files are not touched.
❓DVD-ID reviewOnly appears when some file names could not be recognised. Click to type the right DVD-ID.

The second row — filters and views

Combine them: e.g. Source = Inbox + Badge letters = "E — No English".

SourceWhich movies to show: All, all libraries, only the Inbox, the Pre-Inbox or the duplicates area.
FlagsMovies you marked: fanart mismatch, marked for deletion, playback error, no sound, foreign subtitles, bad English subtitles, wrong disc.
ContentNeeds scraping, needs renaming, complete movies, uncensored with burned subs, censored movies not yet checked for an uncensored version, minor-flagged (review).
Badge lettersFilter by the letters on the cards: has / missing video, fanart, poster, NMP file, burned subs (also by language), transcript (T), English made by Kuraya (E), downloaded English (D), uncensored (U), locked (L).
ViewFanart (wide covers), Poster (tall covers), Favourites, Actors or Series.
SortTitle, ID, actress, library, date, random, recently added / viewed, favourited, series. The ↓ next to it flips the direction.
Card size / themeThe slider changes the card size; the theme button switches dark and light.

The letters on every movie card

Green = present, red = missing. Hover a letter to see the files behind it.

VVideoThe video file is there.
FFanartThe wide cover is there.
PPosterThe tall cover is there.
NNMPKuraya's information file (title, cast, genres…) is there.
BBurnedSubtitles are burned into the picture.
TTranscriptA Japanese or Chinese subtitle made from the audio.
EEnglishEnglish subtitles made by Kuraya.
DDownloadedEnglish subtitles you downloaded.
UUncensoredThe movie is uncensored.
LLockedKuraya will not change this movie automatically.

Right-click on a movie

Everything you can do with one movie.

▶Play MoviePlays it in Kuraya's own player (subtitles load automatically).
🔄Scan This MovieReads just this folder from disk again.
✏️Quick EditChange the title, genres and the sort genres (g1–g4) in one small window.
🌐Scrape MovieAsks the movie sites about this film and shows every answer side by side — pick the best cover, title, cast and genres.
🧪Check Which Scrapers Have This MovieQuick test of which sites know this DVD-ID.
💬Edit / Add SubtitleAttach a subtitle file you have, or make one: Transcribe + Translate turns the movie's audio into English subtitles.
🔧Repair VideoFixes a file that will not play or seek properly.
✂️Scan for Start AdFinds an advert glued to the start of the movie so it can be cut off.
🛠️NMP Re-CreatorRebuilds the information file from what is in the folder.
ℹ️View Movie DetailsAll information about the movie on one page.
📚Show SeriesEvery film of the same series — which you own and which are missing.
📁Open Movie FolderOpens the folder in Explorer.
🖼️Fanart toolsDownload fanart from the internet, search manually, or make a poster from the fanart.
📦Sort into V2 folderMoves the movie to Studio \ genres \ DVD-ID — the same place its badge shows.
📅Change Date Added to TodayMakes it show up under "Recently added" again.
🙈Hide from LibraryRemoves it from Kuraya's list but leaves the files on disk.
🗑️Delete Folder & FilesDeletes the movie for real — Kuraya always asks first.

Working with many movies

Select first, then right-click.

☑️Select several moviesClick the tick box on a card, or Ctrl/Shift-click. The right-click menu then works on all of them.
🌐Bulk Scrape SelectedScrapes all selected movies in one go.
✏️Bulk editQuick Edit, metadata, genres or genre & location for many movies at once.
📏Fix names to 255 ruleShortens folder and file names that are too long for Windows.
🔓Find Uncensored / Eng-Sub VersionsSearches for a better version (uncensored or English-subtitled) of the selected movies.
⭐Favourites, lock, flagsAdd to / remove from favourites, lock or unlock, mark uncensored / censored, flag for review.
📦Move / sort / hide / deleteMove to another folder, sort into the V2 layout, hide or delete several movies at once.

Setup, background jobs and tools

Setup (first start)Choose your folders and download the free helper tools (FFmpeg is required; the others are optional and each says what it is for). Open it again from the welcome screen.
Task Console boxesTranscribe + Translate makes English subtitles for movies without them. Video Converter shrinks big files to HEVC (it checks picture, sound and length before replacing). Metadata Backfill fills missing information. Idle Genre Re-scrape improves genres while you do nothing. Doctor Guard checks the library in small steps. The % on each box shows how much is still to do.
DeepSeek keyWithout a key Kuraya makes free English subtitles with Whisper. With a DeepSeek key (about 3 US cents per movie) the English is much better. Paste it in Setup → Tools or Settings → API Credentials.
Movie SorterIn Media Tools. Series Paths and Sort show where each movie belongs and move it there; Categories, Synonyms and Blacklist come set up already — only change them if you want different genre rules.
Kuraya manages files you own and does not provide any video content. For adults (18+) only.
