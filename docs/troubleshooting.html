Troubleshooting

Try these quick fixes first. Most problems are solved in a minute.

Always first: close Kuraya, open it again, and make sure you have the newest version: Help → Check for updates (the version is shown in the window title).
Kuraya does not start, or closes at once
  1. Run the newest Setup again from Releases. It repairs missing program files and keeps your settings.
  2. Install into the folder Setup suggests, and close Kuraya first.
  3. Windows warns "unknown publisher"? Click More info → Run anyway.
My library stays empty / the welcome screen keeps coming back
  1. New movies first go to the Inbox. Press Process Inbox 📥 to move them into the library.
  2. Already have sorted movies? Check Settings → Folders → Library folders points to them, then press Scan Library 🔄.
  3. Make sure the drive is connected.
A page or window is grey / empty
  1. Close Kuraya and open it again.
  2. Update to the newest version — grey pages are bugs we fix quickly.
  3. Still grey? Use Help → Report a problem so we get the log.
Scraping finds nothing / a site gives an error
  1. Some movie sites need FlareSolverr (in Setup → Tools, needs Docker Desktop). Without it those sites are skipped.
  2. Or install the free browser extension that comes with Kuraya (Edge or Chrome): open edge://extensions, switch on Developer mode, Load unpacked → the Browser extension folder in your Kuraya folder. Keep Edge open while scraping.
  3. Check that the file name contains the DVD-ID (like ABP-112). Rename the file if not, then scrape again.
  4. Try right-click → Check Which Scrapers Have This Movie to see which sites know it.
  5. A site can be down or block for a while — try again later.
No English subtitles appear
  1. Transcription needs Subtitle Edit + Faster-Whisper (Setup → Tools) and works best with an NVIDIA graphics card.
  2. Without a DeepSeek key Kuraya makes free English from the audio — rougher, but automatic. Add a key in Setup → Tools for better English.
  3. The Transcribe + Translate box in the Task Console must be ticked (Auto OFF means nothing starts by itself).
  4. Movies with no speech get no subtitle — that is on purpose.
"FFmpeg is not installed" or no thumbnails
  1. Open Setup → Tools and press Download next to FFmpeg. It is the only required tool.
A movie will not play or the picture is broken
  1. Right-click the movie → Repair Video.
  2. Check the file plays in another player; if not, the file itself is damaged.
The wrong movie / cover / title was found
  1. Right-click → Scrape Movie and pick another result, or Quick Edit to fix the title and genres yourself.
  2. Wrong DVD-ID? Fix the file name, or use the ❓ DVD-ID review button.
Kuraya is slow
  1. Background jobs run in the Task Console — untick the ones you do not need right now, or set Auto OFF.
  2. The first scan of a big library takes a while; later starts use the cache and are fast.
  3. Transcription and video converting use the graphics card — they pause other GPU work.
Something looks wrong in the list (ghost or doubled movies)
  1. Press Clean Cache 🗑️ (top right) — fixes the list in seconds, your files are not touched.
  2. Then Scan Library 🔄 if movies are still missing.

Still not working? Send us a report

How to send a problem report with the log
  1. In Kuraya, click the Help button (blue ?, top right) → Report a problem (with log).
  2. Kuraya puts a file Kuraya-problem-report-….zip on your Desktop and opens our problem page on GitHub.
  3. Write what happened and what you expected, then drag the zip file into the text box and press Submit.

The report contains the Kuraya version, your Windows version, which helper tools are installed, your folder names and the recent log. It never contains passwords, API keys or your movie files. The log can contain movie file names — look inside the zip first if you prefer.

No GitHub account? The log files are in the Logs folder inside your Kuraya folder (newest in Logs\daily).

Kuraya manages files you own and does not provide any video content. For adults (18+) only.
